# StorePOS

Sales, stocks, customer credit and cash closing for Philippine rice stores and small retailers, by **AZ Digital Marketing**.

- `index.html`: product page — features, screen tour, price (₱5,000 one-time, lifetime access) and how to get it.
- `preview.html`: interactive sample-only preview, reset on reload.
- `preview-tour.js` / `preview-tour.css`: the guided tour inside the preview ("Explore demo" → "Next feature →").
- `images/`: 1440×900 screenshots of the preview used on the product page.
- `app/`: local browser edition; records stay on that device.
- `StorePOS-Local.html`: self-contained local download for compatible browsers.
- `version.json`: current version and online activation status.

Internal business records only. Not a registered tax invoice system.

Also from AZ Digital Marketing: [Car Rental Management](https://homearvin.github.io/CAR.RENTAL.BOOKING.MANAGEMENT/) · [QuickCheck](https://homearvin.github.io/QUICK.CHECK/) · [DTR Converter](https://homearvin.github.io/DTR.CONVERTER/).

This repository contains only the public website and downloadable browser edition. Server code and store records belong outside this public repository.
