# StorePOS

Sales, stocks, customer credit and cash closing for Philippine rice stores and small retailers, by **AZ Digital Marketing**.

- `index.html`: product page and setup choices.
- `preview.html`: interactive sample-only preview, reset on reload.
- `app/`: local browser edition; records stay on that device.
- `StorePOS-Local.html`: self-contained local download for compatible browsers.
- `version.json`: current pilot version and online activation status.

Local and online stores have separate records. The online Apps Script edition is awaiting Google authorization and deployment. This is a pilot, not a certified production or registered invoice system.

Also from AZ Digital Marketing: [QuickCheck](https://homearvin.github.io/QUICK.CHECK/) · [DTR Converter](https://homearvin.github.io/DTR.CONVERTER/) · [Car Rental Management](https://homearvin.github.io/CAR.RENTAL.BOOKING.MANAGEMENT/).

This repository contains only the public website and downloadable browser edition. Server code and store records belong outside this public repository.
